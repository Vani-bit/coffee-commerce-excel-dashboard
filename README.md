# Coffee Sales Analytics Dashboard

An interactive Excel dashboard developed to analyze sales performance,
customer behavior and product trends using 1,000 transaction records
from 2019–2022.

## Business Questions

- How have sales changed over time?
- Which countries generate the most revenue?
- Who are the highest-value customers?
- Which coffee products perform best?
- How do purchasing patterns vary by coffee and roast type?

## Tools & Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- XLOOKUP
- Excel Tables
- Data Cleaning
- Data Transformation
- KPI Analysis
- Interactive Slicers
- Dashboard Design

## Data Model

The analysis combines three datasets:

- Orders
- Customers
- Products

Customer and product attributes were mapped into the transaction
dataset using XLOOKUP before performing sales analysis.
